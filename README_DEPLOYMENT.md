## 📋 Deployment Instructions

### Quick Deploy (5 steps)

1. **Clone Repositories**
   ```bash
   git clone https://github.com/Khushicoder04/fitAI-backend.git
   git clone https://github.com/Khushicoder04/fitAI-frontend.git
   ```

2. **Install Dependencies**
   ```bash
   cd backend && npm install
   cd ../frontend && npm install
   ```

3. **Configure Environment**
   ```bash
   # Create .env files with production credentials
   # Backend: MONGODB_URI, JWT_SECRET, STRIPE_SECRET_KEY
   # Frontend: REACT_APP_API_URL
   ```

4. **Build Frontend**
   ```bash
   cd frontend
   npm run build
   # Output: build/ folder
   ```

5. **Deploy**
   ```bash
   # Deploy frontend build/ to static hosting
   # Deploy backend code to Node.js hosting
   # Test all endpoints
   ```
